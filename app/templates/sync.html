Movimentações

Use o período abaixo. Você pode sincronizar somente os módulos necessários.

Sincronização incremental: a plataforma mantém o cursor principal de cada módulo e, a partir desta versão, também grava um índice local das páginas/offsets já percorridos (datas, IDs, quantidade e assinatura do conteúdo). A rotina normal continua revalidando a borda recente para encontrar documentos novos, mas reaproveita o índice quando ele ajuda a localizar períodos já conhecidos.

Forçar sincronização

Use somente quando precisar reconsultar deliberadamente um período específico. O processo ignora a cobertura já concluída para os documentos, mas preserva o cursor incremental principal. Se o intervalo já estiver no índice local, a plataforma começa diretamente nas páginas/offsets conhecidos.

AUDITORIA / RECUPERAÇÃO

Importante: esta rotina faz novas chamadas à API mesmo para registros já existentes. A gravação continua por atualização/upsert, portanto não cria uma segunda NF/título apenas por reprocessar o período.
